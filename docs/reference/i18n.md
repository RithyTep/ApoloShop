## Supported Languages

| Code | Language |
|------|----------|
| `en` | English (default) |
| `kh` | Khmer (ភាសាខ្មែរ) |

---

## Usage

### In Components

```tsx
import { useI18n } from '@/providers/i18n-provider'

function Component() {
  const { t, language, setLanguage } = useI18n()

  return (
    <div>
      <h1>{t('welcome')}</h1>
      <button onClick={() => setLanguage('kh')}>ខ្មែរ</button>
    </div>
  )
}
```

### Product Names

Products have bilingual fields:

```tsx
function ProductCard({ product }) {
  const { language } = useI18n()

  const name = language === 'en' ? product.nameEn : product.nameKh
  const description = language === 'en' ? product.descriptionEn : product.descriptionKh

  return <div>{name}</div>
}
```

## Adding Translations

### 1. Update Translation File

```typescript
// lib/i18n/translations.ts

export const translations = {
  en: {
    // Existing translations
    welcome: 'Welcome',
    // Add new key
    newFeature: 'New Feature',
  },
  kh: {
    welcome: 'សូមស្វាគមន៍',
    newFeature: 'មុខងារថ្មី',
  }
}
```

### 2. Use in Component

```tsx
const { t } = useI18n()
<span>{t('newFeature')}</span>
```

## Currency

### Supported Currencies

| Code | Symbol | Format |
|------|--------|--------|
| `USD` | $ | $15.50 |
| `KHR` | ៛ | ៛63,550 |

### Exchange Rate

Default: 1 USD = 4,100 KHR (configurable in settings)

### Formatting

```tsx
import { formatCurrency } from '@/lib/utils'

// Format with currency symbol
formatCurrency(15.50, 'USD') // "$15.50"
formatCurrency(63550, 'KHR') // "៛63,550"

// Convert currencies
const khrAmount = usdAmount * exchangeRate
```

## Database Fields

All content tables have bilingual fields:

| English Field | Khmer Field |
|---------------|-------------|
| `name_en` | `name_kh` |
| `title_en` | `title_kh` |
| `description_en` | `description_kh` |
| `content_en` | `content_kh` |

## Language Switcher

```tsx
function LanguageSwitcher() {
  const { language, setLanguage } = useI18n()

  return (
    <div className="flex gap-2">
      <Button
        variant={language === 'en' ? 'default' : 'outline'}
        onClick={() => setLanguage('en')}
      >
        EN
      </Button>
      <Button
        variant={language === 'kh' ? 'default' : 'outline'}
        onClick={() => setLanguage('kh')}
      >
        ខ្មែរ
      </Button>
    </div>
  )
}
```
