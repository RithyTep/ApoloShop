# Ralph Progress Log
Started: 2025-01-12
Project: ApoloShop - Product Search Feature

## Codebase Patterns
- Components use kebab-case: `shop-header.tsx`
- UI primitives from Shadcn: `components/ui/`
- Translations in `lib/i18n.ts` with EN/KH keys
- API routes: `app/api/*/route.ts` with Prisma
- Use React Query hooks from `lib/api-hooks.ts`
- Commit format: `[feat] description` or `[fix] description`

## 2026-01-12 - US-001
- **Implemented**: Search API endpoint GET /api/products/search
- **Files changed**:
  - `app/api/products/search/route.ts` (new file)
  - `scripts/ralph/prd.json` (updated passes: true)
- **Features**:
  - Accepts `?q=` query parameter for search term
  - Searches in nameEn, nameKh, descriptionEn, descriptionKh fields
  - Returns matching products with category info (id, nameEn, nameKh, slug)
  - Handles empty query gracefully (returns empty array)
  - Optional `?limit=` parameter (default 10)
- **Learnings for future iterations**:
  - Existing `/api/products` route has a `search` param but only searches name/sku, not description
  - Prisma `contains` with `mode: "insensitive"` works for case-insensitive search
  - Only return active products (`isActive: true`) for customer-facing search

## 2026-01-12 - US-003
- **Implemented**: Search results dropdown with debounced API calls
- **Files changed**:
  - `components/search-dropdown.tsx` (new file)
  - `components/header.tsx` (modified - integrated SearchDropdown)
  - `scripts/ralph/prd.json` (updated passes: true)
- **Features**:
  - 300ms debounce on search input before API call
  - Dropdown shows below search input with product results
  - Displays product image (with placeholder for missing images), name, and price
  - Bilingual "No results found" / "រកមិនឃើញលទ្ធផល" message
  - Skeleton loading state with "Searching..." / "កំពុងស្វែងរក..." text
  - Click outside to close dropdown
  - Currency-aware price display (USD/KHR)
  - Language-aware product name display (EN/KH)
- **Learnings for future iterations**:
  - SearchDropdown is separate component for reusability
  - Uses `useRef` + `mousedown` event for click-outside detection
  - Dropdown positioned with `absolute top-full` relative to search input container
  - Price formatting uses `Number()` conversion since Prisma Decimal comes as string
  - Search API returns max 5 results via `limit=5` param for dropdown brevity
